# 演出ファイル

1ファイル1演出。ファイル名が演出のIDになる。追加したらアプリを起動しなおす。

```toml
name = "ノーマル"
weight = 80   # ランダムのときの出やすさ

steps = [
  { fix = "00000", ms = 600 },
  { fix = "10000", ms = 600, sound = "test.wav" },
  { fix = "11111", ms = 900, sound = "test.wav" },
]
```

上から順に進んで、最後まで行ったら名前を出す。

- `{ fix = "11000", ms = 500 }` 1の桁を止めて0の桁を回す。msミリ秒
- `{ action = "blank" }` 回さずに「-」を出しておく
- `{ action = "roll", order = "5432", every = 160, sound = "test.wav" }` 全部回してから 5,4,3,2 桁目の順に every ms ごとに止める
- `{ action = "redraw" }` 当選者を選びなおす
- `{ action = "fake", number = "88888" }` 番号の代わりに88888を出す (redrawで戻る)
- `{ action = "flash", on = true }` 虹フラッシュ開始 (`on = false` で終わり)
- `{ action = "colors", bg = "#000000", fg = "#d7000f" }` 背景と文字の色を変える (次の抽選で元に戻る)
- `{ action = "message", text = "再抽選" }` 名前のところに文字を出す
- `{ action = "sound", sound = "8.wav" }` 音だけ鳴らす
- `{ action = "wait", ms = 300 }` 何も変えずに待つ (sound も付けられる)

1行に `{ ... }, { ... },` と何個か並べて書いてもいい。

`sound` は `music/` から探す (`yokai/OH.wav` のようにフォルダも書ける)。ステップの最初に鳴る。
`wait = true` を付けると、その音が鳴り終わるまで次に進まない (速さの設定に関係なく音の長さだけ待つ)。

## 音ハメ

`ms` の代わりに `at` を書くと、前の `zero = true` のステップが始まってから何ms後に始めるかで決められる。
1か所変えても他がずれないので、曲に合わせるときはこっちを使う (速さの設定は効かない)。

```toml
  { fix = "00000", sound = "vivant/MUSIC.wav", zero = true },
  { fix = "10000", at = 3170 },   # MUSIC が始まって3.17秒で1桁目
  { fix = "11000", at = 4150 },
```

設定の「演出」→「試し再生」で「記録」を押すと、`at` のところは T を押すまで進まない。
曲を聞きながら止めたいところで T を押していき、最後に「書き換えますか？」ではいを押すと、その時刻が `at` に入る。

`start_sound = ""` を書くと、その演出ではスタートボタンの音 (push.wav) を鳴らさない。

`order_` で始まるファイルは設定画面の桁順モードで作ったもの。
